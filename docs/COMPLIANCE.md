Traceability from each normative requirement to code and tests. A requirement without
a passing test is not implemented. Rows are added when tasks merge.

Note: implementing a calculation method per a standard is not the same as a certified
instrument (IEC 61672-1 / IEC 61260-1 conformance concerns the whole measuring chain).
Results state this. Filter conformance to IEC 61260-1 is NOT verified (Q-S1).
